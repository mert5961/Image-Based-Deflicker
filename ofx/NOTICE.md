# Licensing status

The frame-access probe and its test harness are newly written integration code submitted for maintainer review. The repository's contribution and redistribution licence is awaiting clarification in the upstream discussion. A project licence has not been selected on the maintainer's behalf.

The files under `vendor/openfx` are third-party OpenFX headers covered by the BSD licence reproduced in that folder. They come from AcademySoftwareFoundation/openfx at commit `1769a91c3a5dd0b859a0618395bb08165486460d`.

The probe does not contain a port of the existing Python deflicker processing code.
